Build instruction:
1. To execute build_codes.sh, please go to sorc/stofs_2d_glo/ directory.
2. cd to the /sorc/stofs_2d_glo/ direcotry
3. make sure that stofs_2d_glo_build is avaiable.
4. to build all executables:
   ./build_codes.sh   
5. to build with debug options
   ./build_codes.sh debug
6. to clean all executables:
   make clean

Note: build_code.sh doesn't include to compile adcirc,if you build adcirc under /sorc, please go to /adcirc.
Please run ./build-all.
